# Ran's Shelter Plugins

This is my sloppy collection of plugins for [Shelter](https://github.com/uwu/shelter)!

## Plugins

### Favorite Media
`https://ran-mewo.github.io/shelter-plugins/favorite-media/`

This plugin allows you to favorite images and videos which are then shown in the GIF picker.

### Channel Export
`https://ran-mewo.github.io/shelter-plugins/channel-export/`

This plugin downloads every message in a channel, from the very first to the latest, as JSON or plain text. Click the download button at the top of a channel to pick a format and whether to ignore humans or apps.
